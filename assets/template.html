⬇ 导出 KML（奥维 / 两步路 / 高德网页版）

已自动尝试下载。如果浏览器没有弹出保存——微信内置浏览器、预览面板会拦下载——用下面两个按钮任选其一。

手机微信里：右上角 ··· → 在浏览器中打开，再点「保存为文件」。
复制成功后：打开备忘录 / 记事本 → 粘贴 → 存为 —（KML 是纯文本，手动改名也行）。
用高德打开：手机高德 App 不能直接导入 KML，得绕电脑。① 只看轨迹：电脑开高德地图 → 顶部「新功能」→「KML/GPX 轨迹导入」→ 拖入本文件（只画行车线，点位不显示）。 ② 能上手机：电脑开 wia.amap.com →「创建新地图」→「批量导入」→ 数据来源选「谷歌地图」（选高德会失败）→ 手机高德 App「我的 → 地图小程序」里看，点位和路线都在。
本文件是 WGS-84 坐标，高德会自动纠偏，不用手动改。
说实话：手机上最省事的不一定是 KML——直接点气泡里的「高德导航」更直接（记得在浏览器里打开）。
